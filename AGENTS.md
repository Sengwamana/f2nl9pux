# Project instructions

## Required context for every task

Before answering or changing anything in this repository, read all six project context documents:

1. `project-overview.md`
2. `architecture-context.md`
3. `code-standards.md`
4. `ui-context.md`
5. `ai-workflow-rules.md`
6. `progress-tracker.md`

Treat these documents as project context, not as proof that planned work has been implemented. Check the repository when a task depends on current implementation or status. If a document conflicts with the user's latest instruction, follow the user and update the affected documentation when appropriate. If a document conflicts with repository evidence, report and correct the stale documentation rather than repeating it as fact.

For a narrow task, still load all six documents first; then apply only the relevant details. Keep context documents aligned with code and update the progress tracker when status changes.
